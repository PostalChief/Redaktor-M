# Redaktor-M

Лёгкий текстовый редактор для Windows с современным интерфейсом, палитрой команд и подсветкой синтаксиса Python.

![Иконка](app.ico)

## ✨ Возможности

- 🎨 Тёмная тема, номера строк, вкладки
- ⌨️ Палитра команд (`Ctrl+Shift+P`) с fuzzy-поиском
- 📂 Fuzzy-навигация по файлам (`Ctrl+P`)
- 🔍 Поиск и замена с regex (`Ctrl+F` / `Ctrl+H`)
- 🐍 Подсветка синтаксиса Python
- 💾 Автосохранение с настраиваемой задержкой
- 🌐 Локализация: русский / английский
- 📋 Список недавних файлов
- 🔤 UTF-8 с BOM (опционально)
- 🔄 Сохранение сессии
- 🖱️ Интеграция с контекстным меню Windows

## 📥 Установка

1. Скачайте `Redaktor-M-Setup.exe` из раздела [Releases](../../releases)
2. Запустите и следуйте мастеру
3. Поставьте галочку «Добавить в контекстное меню»

## 🖥️ Системные требования

- Windows 10 / 11 (x64)
- ~200 МБ свободного места
